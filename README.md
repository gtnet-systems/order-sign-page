# order-sign-page

GTNET 見積・注文 承認システム ── **お客様の署名ページ（静的ホスティング版）**

このリポジトリには `sign.html` の1枚しか置きません。
システム本体は非公開リポジトリ [`order-approval-system`](https://github.com/gtnet-systems/order-approval-system) にあります。

---

## なぜ、このリポジトリがあるのか

お客様へお送りする署名URLを **Android で開くと `/u/2` が挿入され、開けません**でした。

```
送ったURL　　：https://script.google.com/macros/s/AKfy……/exec?t=…
飛ばされた先　：https://script.google.com/macros/u/2/s/AKfy……/exec?t=…
```

`/u/2` を差し込むのは、Android Chrome が `script.google.com` を
**「トップレベルのページとして開く」その瞬間**です。
中継ページ・302転送・meta refresh では直りません。

**署名ページを自社ホスティングの静的ページにし、GAS は API として fetch で呼ぶ。**
別ドメインからの fetch は Cookie を送らないため、Google は匿名として扱い、
`/u/N/` を付ける動機が消えます。お客様のブラウザは二度と `script.google.com` を
ページとして開きません。だから構造的に再発しません。

（GTNET自動車保険システムが 2026-07-19 に実施し、本番で解決確認済みの方法です）

---

## ★このリポジトリは公開です

GitHub Pages の無料枠で配信するため、公開リポジトリにしています。

**置いてよいもの**

- `sign.html`（画面のHTML・CSS・JavaScript）
- GASウェブアプリの `/exec` URL
  （お客様へお送りするメール本文に毎回書いてあるものです。隠せている情報ではありません）

**絶対に置かないもの**

- お客様の氏名・金額・電話番号など、実データの一切
- トークン、APIキー、パスワード、スプレッドシートのID、DriveのファイルID
- 社内の手順書・引継ぎ書

画面に出るデータは、すべて実行時に GAS から取得します。
**このファイルの中に、お客様の情報は1文字もありません。**

## 中身

| ファイル | 内容 |
|---|---|
| `sign.html` | お客様の署名ページ |

`sign.html` は、本体リポジトリの `src/customer/C10_page.html` から作っています。
**違うのは、ファイルの頭とお尻だけ**です（タイトル・通信部分・起動処理）。
画面の見た目とロジックは1行も違いません。

### ★両方を直さないこと

旧方式（GASがHTMLを返す `C10_page.html`）は、切り戻しのために当面残してあります。
**この期間だけ、同じ画面が2つ存在します。**
画面を直すときは、必ず両方に同じ変更を入れてください。

数日の運用で問題が無ければ、`C10_page.html` を撤去して1本化します。
そのときこの注意書きは消えます。

## 設定

`sign.html` の先頭に1か所だけあります。

```js
var GAS_API = 'https://script.google.com/macros/s/AKfy……/exec';
```

お客様向けGASウェブアプリの `/exec` URL です。
**新しいデプロイを作るとURLが変わり、送信済みメールのリンクが全部死にます。**
更新は必ず「デプロイを管理 → 編集（鉛筆）→ バージョン＝新バージョン」で行ってください。

---

## 公開URL

```
https://gtnet-systems.github.io/order-sign-page/sign.html?t=（トークン）
```

このURLは、本体の `settings『署名WebアプリURL』` の1セルに入っています。
**旧方式へ戻したいときは、そのセルを `/exec` のURLに戻すだけです。**

## 直したあとの確認

ブラウザのキャッシュに惑わされます。配信中の中身を確かめるには：

```
view-source:https://gtnet-systems.github.io/order-sign-page/sign.html
```

を開いて、期待する文字列（例：`GAS_API`）を検索してください。

## Androidでのテスト

**シークレットタブでテストしないでください。**
未ログイン扱いになり、旧URLでも開けてしまうため、切り分けになりません。

必ず**通常タブ**で行い、失敗したときは**アドレスバーが `/macros/u/N/s/…` に
なっているか**を確認してください。これが唯一確実な判定方法です。
